# 重财‑论文格式规范
> Chongqing University of Finance and Economics Thesis Formatter

**重庆财经学院本科毕业论文自动化排版工具**
同时输出 **Word(DOCX)** + **LaTeX(XeLaTeX)**，严格遵循学校《毕业论文（设计）指导手册》，**不采用 GB/T 7713.2‑2022**。仅处理格式，不修改论文内容、观点与数据。

## ✨ 项目特性
- 📄 **双格式输出**：一键生成 `DOCX`（Word）与 `TeX`（LaTeX）两份成品
- 📐 完整复刻学校官方格式规范
  - 页面设置：A4纸张，左页边距2.8cm，上/下/右2.5cm，全文固定行距26磅
  - 页码规则：前置部分（摘要、目录）大写罗马数字 `Ⅰ、Ⅱ、Ⅲ`；正文阿拉伯数字 `1、2、3`；封面无页码
  - 四级标题体系：`一、` → `（一）` → `1.` → `（1）`
  - 中英文摘要、关键词；中文关键词全角分号，英文关键词半角分号
  - 图表编号格式 `图 1‑1` / `表 1‑1`；图题置于图下方，表题置于表上方，支持三线表
  - 公式编号 `(1.1)` 右对齐，按章节编号
  - 参考文献悬挂缩进2字符；正文引用自动设置上标 `[1]`
  - 目录仅渲染一、二级标题，点号前导符，修复目录更新后文字变蓝问题
- 🛡️ 安全机制：**只调整格式，绝不改写论文文字、观点、数据、参考文献**；默认不覆盖原始文件
- ✅ 内置交付验收检查清单，输出前自动校验关键格式项

## 🚀 使用方法
### 1. Word(DOCX) 工作流
1. 上传你的原始论文 `*.docx` 文件
2. 触发指令：`按重财规范调整格式`
3. 获取输出文件：`原文件名_重财规范版.docx`
4. 可直接打开Word复核，另存导出PDF用于提交

> ⚠️ PDF仅可用来查看校验格式，**不可直接编辑PDF**。源文件务必保留docx。

### 2. LaTeX(.tex) 工作流
1. 执行排版后同步输出：`原文件名_重财规范版.tex`
2. **必须使用 XeLaTeX 引擎编译**（支持中文）
3. 编译至少**两次**，用于渲染目录、参考文献编号
4. 直接生成符合学校规范的PDF文档

> 模板内置全部页面、标题、图表、参考文献配置，无需手动调整大量参数。

## 📑 格式依据
> 全部排版规则来源于 **重庆财经学院《毕业论文（设计）指导手册》**
> ❗ **本项目不采用 GB/T 7713.2‑2022 国家标准**，一切以本校手册为准。

### 页面关键参数
| 项目 | 参数 |
|---|---|
| 纸张 | A4 21cm × 29.7cm |
| 页边距 | 左：2.8cm；上/下/右：2.5cm |
| 页眉 | 1.5cm |
| 页脚 | 1.75cm |
| 行距 | 固定值 26磅（表格注释除外） |

### 文档装订顺序
`封面` → `中文摘要（含关键词）` → `英文摘要（含Keywords）` → `目录` → `正文` → `参考文献` → `附录（可选）`

## ⚠️ 注意事项
1. 工具**仅负责格式排版**，不校验论文逻辑、语法、学术内容正确性。
2. LaTeX模板依赖 XeLaTeX，PDFLaTeX 会出现中文乱码。
3. 不会修改你的原始论文文件，输出文件带后缀 `_重财规范版`。
4. 目录生成后务必执行一次更新域操作。
5. 图表建议提前整理好，工具只调整图题、表题格式，不修改图片内容。

## 📋 交付验收检查清单
输出完成会核对以下项目：
- [ ] Word文档可正常打开，无字体缺失乱码
- [ ] 页面边距、行距参数正确
- [ ] 标题层级一至四级编号格式无误
- [ ] 页码分节：前置罗马数字，正文阿拉伯数字
- [ ] 目录仅展示到二级标题，页码前导符为点号
- [ ] 图、表编号格式 `图 1‑1`、`表 1‑1`
- [ ] 正文参考文献引用全部为上标格式
- [ ] 参考文献悬挂缩进2字符
- [ ] 可正常导出PDF
