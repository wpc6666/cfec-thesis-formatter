# 重财-论文格式规范 v1.1.0

将重庆财经学院本科毕业论文调整为符合该校《毕业论文（设计）指导手册》的格式，**同时输出 DOCX 和 LaTeX 两个版本**。

**格式权威依据**：所有字体字号、页面设置、页码规则、编号样式等详细参数见 [references/format-spec.md](references/format-spec.md)，执行时必须读取该文件。

**LaTeX 模板**：见 [assets/chongqing-caijing-thesis.tex](assets/chongqing-caijing-thesis.tex)，使用说明见 [references/latex-guide.md](references/latex-guide.md)。

**更新日志**：见 [CHANGELOG.md](CHANGELOG.md)。

---

## 核心原则

- **只改格式，不改内容**：不修改论文文字、观点、数据、参考文献条目。
- **双版本输出**：默认同时生成 DOCX 和 LaTeX 两个版本。
- **不覆盖原文件**：输出新文件，命名为 `原文件名_重财规范版.docx` 和 `原文件名_重财规范版.tex`。
- **以重财手册为准**：不采用 GB/T 7713.2-2022 或其他高校规范。
- **可追溯**：每一步格式调整都有明确依据，输出前逐项自检。

## 工作流

### Step 0：前置检查（v1.1.0 新增）

在开始处理前，必须完成以下检查：

1. **输入完整性检查**
   - 确认用户提供了论文内容（文件或文本）。
   - 确认论文包含：封面信息、中文摘要、英文摘要、正文、参考文献。
   - 缺少部分向用户说明，用占位符标注，不编造内容。

2. **环境检查**
   - DOCX 生成：确认可用 python-docx 库或 Word 文档操作能力。
   - LaTeX 生成：确认可读取模板文件，输出 `.tex` 源码。
   - 若环境不支持某一版本，明确告知用户，只输出支持的版本。

3. **格式规范加载**
   - 读取 [references/format-spec.md](references/format-spec.md)，加载全部格式参数。
   - 读取 [assets/chongqing-caijing-thesis.tex](assets/chongqing-caijing-thesis.tex)，作为 LaTeX 输出基础模板。

---

### Step 1：确认输入与输出

1. 获取用户提供的论文文件（`.docx` 或文本内容）。
2. 确认输出：同时生成两个版本——
   - `原文件名_重财规范版.docx`
   - `原文件名_重财规范版.tex`（LaTeX 源码）
3. 若用户只需要其中一个版本，按用户要求输出。

## DOCX 版本工作流

### Step 2：页面设置（DOCX）

1. 纸张：A4（21cm × 29.7cm）。
2. 页边距：左 2.8cm，右/上/下各 2.5cm。
3. 装订线 0cm，位置靠左。
4. 页眉 1.5cm，页脚 1.75cm。
5. 全文行距设为固定值 26 磅（表格、注释除外）。

### Step 3：分节与页码（DOCX）

1. 在封面后插入分节符（下一页），在目录后/正文前插入分节符（下一页）。
2. 各节取消"链接到前一条页眉"。
3. 封面：无页码。
4. 前置部分（摘要、Abstract、目录）：大写罗马数字 Ⅰ、Ⅱ、Ⅲ……，底端居中，Times New Roman 小四号。
5. 正文部分：阿拉伯数字 1、2、3……，从正文第一页开始编号为 1，底端居中，Times New Roman 小四号。

### Step 4：封面与摘要（DOCX）

1. **封面**：题目及各项信息（学院、年级、专业、学号、姓名、指导教师）均为宋体/Times New Roman、四号、加粗、居中。
2. **中文摘要**：
   - 标题"摘要"：黑体、小三号、加粗、居中，"摘""要"间空 2 个半角空格。
   - 内容：宋体/Times New Roman、小四号，首行缩进 2 字符，固定行距 26 磅。
   - "关键词："：黑体小四号，与摘要内容空一行；关键词内容宋体小四号，之间用全角分号"；"。
3. **英文摘要（Abstract）**：
   - 标题"Abstract"：Times New Roman、小三号、加粗、居中。
   - 内容：Times New Roman、小四号，首行缩进 2 字符。
   - "Keywords:"：Times New Roman 小四号，关键词之间用半角分号";"。

### Step 5：标题层级与正文（DOCX）

1. 将正文各级标题按以下体系设置并应用对应 Word 样式（一级用 Heading 1，二级用 Heading 2，用于目录生成）：

   | 级别 | 编号 | 字体字号 | 对齐 |
   |------|------|---------|------|
   | 一级 | 一、二、三… | 黑体小三号加粗 | 居中，与上文空一行 |
   | 二级 | （一）（二）… | 黑体四号 | 首行缩进 2 字符 |
   | 三级 | 1. 2. 3… | 黑体小四号 | 首行缩进 2 字符 |
   | 四级 | （1）（2）… | 宋体小四号加粗 | 首行缩进 2 字符 |

2. **正文文本**：宋体/Times New Roman、小四号，两端对齐，首行缩进 2 字符，固定行距 26 磅。

### Step 6：生成目录（DOCX）

1. 确认一级标题已应用 Heading 1，二级标题已应用 Heading 2。
2. 在目录页插入 Word TOC 域，设置显示级别为 2。
3. 目录标题"目录"：黑体、小三号、加粗、居中，两字间空 2 个半角空格。
4. 目录一级项：宋体/Times New Roman 小四号，无缩进；二级项：左缩进 2 字符。
5. 页码右对齐，制表符前导符为点号（……）。
6. 更新目录域后，全选目录检查字体颜色——若变为蓝色超链接样式，强制改回黑色（自动）。

### Step 7：图表与公式（DOCX）

1. **图**：图序图题置于图下方，黑体五号居中，格式为"图 1-1 ×××"（图与编号间有空格，按章节编号）。
2. **表**：表序表题置于表上方，黑体五号居中，格式为"表 1-1 ×××"；表格优先三线表，表内文字宋体/Times New Roman 五号。
3. **注/资料来源**：宋体/Times New Roman 小五号，首行缩进 2 字符，单倍行距。
4. **公式**：单独成行，Times New Roman 小四号；编号按章节形如（1.1），右对齐。

### Step 8：参考文献与引用上标（DOCX）

1. "参考文献"标题：黑体、小三号、加粗、居中，另起一页。
2. 参考文献条目：宋体/Times New Roman 五号，悬挂缩进 2 字符，固定行距 26 磅，编号 [1] [2]… 按正文出现顺序排列。
3. **正文引用上标检查**：正文中所有参考文献引用（如 [1]、[4-6]）必须设为上标，Times New Roman 小四号。参考文献列表本身的编号不上标。
4. 验收标准：未上标的正文引用数量 = 0。

### Step 9：附录（DOCX，如有）

1. 附录编号"附录 A""附录 B"…：黑体、小三号、加粗、居中。
2. 附录标题：黑体、四号、居中。
3. 附录条文：宋体/Times New Roman、小四号，首行缩进 2 字符。

## LaTeX 版本工作流

### Step 10：生成 LaTeX 源码

基于 [assets/chongqing-caijing-thesis.tex](assets/chongqing-caijing-thesis.tex) 模板，将论文内容填入对应位置：

1. **复制模板**：将模板文件复制为 `原文件名_重财规范版.tex`。
2. **封面**：替换 titlepage 环境内的题目、学院、年级、专业、学号、姓名、指导教师、日期。
3. **中文摘要**：替换摘要正文和关键词（关键词间用全角分号"；"）。
4. **英文摘要**：替换 Abstract 正文和 Keywords（关键词间用半角分号";"）。
5. **正文**：使用自定义标题命令撰写，**禁止使用标准 \section/\subsection**：
   - `\h1{第一章标题}` → 一级，"一、"编号，黑体小三号加粗居中
   - `\h2{二级标题}` → 二级，"（一）"编号，黑体四号首行缩进
   - `\h3{三级标题}` → 三级，"1."编号，黑体小四号首行缩进
   - `\h4{四级标题}` → 四级，"（1）"编号，宋体小四号加粗首行缩进
6. **图表**：
   - 图片用 `figure` 环境，`\caption{}` 置于 `\includegraphics` 之后（图题在下方），自动编号"图 1-1"
   - 表格用 `table` 环境，`\caption{}` 置于 `tabular` 之前（表题在上方），推荐 `booktabs` 三线表，自动编号"表 1-1"
7. **公式**：用 `equation` 环境，自动编号（1.1）右对齐。
8. **参考文献**：在 `therefs` 环境中用 `\item` 逐条添加，自动悬挂缩进 2 字符、五号字。正文引用用 `\cite{key}` 自动上标。
9. **附录**（如有）：复制附录 A 块，改编号为"附录 B"等。
10. **页码与目录**：模板已自动处理——封面无页码、前置部分大写罗马数字、正文阿拉伯数字从1开始；目录只显示到二级，点号前导符。

### Step 11：LaTeX 格式校验

对照 [references/latex-guide.md](references/latex-guide.md) 检查：

1. 编译器设置为 **XeLaTeX**（非 PDFLaTeX）。
2. 所有标题使用 `\h1`–`\h4` 命令，未使用标准 `\section` 等。
3. 图题在 `\includegraphics` 之后，表题在 `tabular` 之前。
4. 中文关键词用全角分号"；"，英文用半角分号";"。
5. 参考文献在 `therefs` 环境内，每条用 `\item`。
6. 正文引用使用 `\cite{}`，未手动打上标。
7. 编译两次以生成目录和交叉引用。

## 错误处理与回退（v1.1.0 新增）

### 常见错误及处理

| 错误场景 | 处理方式 |
|---------|---------|
| DOCX 生成失败 | 回退为输出格式说明文档，告知用户手动调整步骤 |
| LaTeX 模板读取失败 | 输出最小可用模板，标注缺失部分 |
| 论文内容不完整 | 用占位符标注缺失部分，不编造内容 |
| 字体不可用 | 说明替代字体，优先保证格式结构正确 |
| 目录生成异常 | 手动列出目录结构，标注需用户在 Word 中更新域 |

### 降级原则

- 双版本输出失败时，至少保证一个版本完整输出。
- 复杂格式（如自动目录）失败时，输出手动操作指南。
- 永远不因为格式处理失败而修改论文内容。

## 允许与禁止

**允许**：删除临时格式说明；调整标题层级、目录、页码、字体字号、图表题注、参考文献列表外观；统一正文引用编号为上标；将论文内容填入 LaTeX 模板对应位置；输出格式自检报告。

**禁止**：改写观点、增删论据、编造文献、补充身份信息、修改数据结果、覆盖原文件、在 LaTeX 中使用标准 \section 替代自定义 \h1–\h4 命令、在未告知用户的情况下省略输出版本。
