🏫 关于重庆财经学院

重庆财经学院是重庆民办最好大学之一，专注财经类应用型人才培养。本项目面向本校本科毕业生，一键输出符合学校《毕业论文（设计）指导手册》规范的 Word 与 LaTeX 文档，仅调整格式，不修改论文原文内容。

  • A4纸张，左页边距2.8cm，上/下/右2.5cm，全文固定行距26磅
  • 前置摘要目录罗马页码；正文阿拉伯页码；封面无页码
  • 标题层级：一、 →（一）→1.→(1)
  • 图表编号、公式右对齐编号、参考文献悬挂缩进、三线表完整支持

✨ 项目特性

  • 双格式输出：一键生成 DOCX(Word) 与 TeX(LaTeX‑XeLaTeX) 两份成品
  • 严格复刻学校官方全部格式细则
  • 安全机制：只修改格式，绝不改写论文文字、参考文献；默认不覆盖原始文件
  • 内置交付校验清单，输出前自动校验关键格式项

📦 安装 Skills

1. 获取 SKILL.md

git clone https://github.com/wpc6666/cfec‑thesis‑formatter.git
cd cfec‑thesis‑formatter

2. Hermes‑Agent / DeepSeek‑Harness 加载 Skill

# 将 SKILL.md 复制到 agent skills 目录
cp SKILL.md ~/.harness/skills/
注意：重启 Agent / Harness 服务，技能才会被索引加载。

🛒 作为 Marketplace 市场接入

marketplace.json 配置要点

{
  "name":"cfec‑thesis‑formatter",
  "description":"重庆财经学院毕业论文格式排版Skill",
  "skills":["SKILL.md"],
  "author":"wpc6666",
  "repo":"https://github.com/wpc6666/cfec‑thesis‑formatter"
}
  • 把 marketplace.json 放置在仓库根目录
  • 在 Harness Marketplace 配置中添加本仓库地址作为源
  • 刷新市场列表，即可看到本工具，一键安装Skill

⚙️ 如何调用 Skills

方式一：对话直接调用

直接向 Agent 发送指令示例：

使用 cfec‑thesis‑formatter skill，处理我的毕业论文，输出符合重庆财经学院规范的docx与xelatex文档。

方式二：API / Programmatic 调用

# harness api 调用示例
POST /v1/agent/skill/run
{
  "skill_id":"cfec‑thesis‑formatter",
  "payload":{"thesis_text":"你的论文文本内容"}
}
提示：调用前确认Skill已经被索引；如果调用无响应，检查日志看是否读取 SKILL.md 成功。

📖 使用说明

基础流程

  1. 准备你的论文文本，不要自行调整复杂格式
  2. 加载本项目Skill，传入论文内容
  3. Agent 输出标准化 Word(DOCX)、XeLaTeX源文件
  4. 本地打开，预览核对图表、参考文献，直接用于提交

限制说明

  • 不会修改你的论文正文观点、数据
  • 复杂图片需要你自己保证图片资源完整
