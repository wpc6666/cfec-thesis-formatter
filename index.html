📖 项目简介
重庆财经学院本科毕业论文 · 自动化排版工具

重财·论文格式工具 是专为重庆财经学院本科毕业生打造的 自动化排版解决方案。只需一个命令，就能将你的论文 一键转换为符合学校《毕业论文（设计）指导手册》格式规范的 Word (DOCX) 和 LaTeX (XeLaTeX) 双格式文件。

🎯 零误差 📄 双格式 ✏️ 不改内容 🚀 一键生成

设计理念： 只处理格式，绝不修改论文正文、观点、数据与参考文献， 保证学术完整性。让你从繁琐的格式调整中解放出来，专注于内容本身。

📤
双格式输出
同时生成 DOCX 和 TeX 文件，满足不同提交需求
📐
严格复刻官方规范
页边距、行距、页码、标题层级、参考文献 100% 复刻
🔒
内容零修改
仅调整格式，你的观点、数据、参考文献完全保留
🤖
AI 友好
支持在 AI Agent 中直接调用，对话式完成排版
⚡ 快速开始
三步搞定论文排版 ✧ 超简单
  1. 安装 — 在终端执行 pip install cfec-thesis-formatter 或在 AI 对话中说 “请安装 cfec-thesis-formatter”
  2. 使用 — 在 AI 对话中上传你的论文，说 “请用 cfec-thesis-formatter 帮我排版”
  3. 完成 — 下载生成的 Word 或 LaTeX 文件，直接提交 ✨
👤 你：“请用 cfec-thesis-formatter 帮我排版这篇毕业论文”
🤖 AI：“好的，正在为您排版…… 已生成 DOCX 和 TeX 文件，请查收 ✧”

📦 安装指南
两种安装方式，任选一种即可 ✧

💻 方式一：终端安装

打开你的 终端（Mac/Linux 叫 Terminal，Windows 叫 命令提示符 或 PowerShell），复制粘贴下面的命令，按回车即可：

pip install cfec-thesis-formatter

或者，如果你想使用最新开发版：

git clone https://github.com/wpc6666/cfec-thesis-formatter cd cfec-thesis-formatter pip install -e .

✅ 安装成功后，你就可以在 AI 对话中使用这个工具了。

🤖 方式二：AI Agent 内安装

如果你使用的是支持工具调用的 AI 助手（如 Claude、GPT 等），可以直接在对话中告诉 AI 帮你安装：

👤 你：“请帮我安装 cfec-thesis-formatter 这个论文排版工具”
🤖 AI：“好的，正在为您安装 cfec-thesis-formatter…… 安装完成！现在您可以上传论文进行排版了 ✧”

💡 这种方式最适合小白用户 —— 你不需要打开终端，全部在对话中完成。

📐 格式规范
严格遵循重庆财经学院《毕业论文（设计）指导手册》
📏
页边距
上 2.5cm，下 2.5cm，左 3cm，右 2.5cm
📝
行距
正文 1.5 倍行距，标题适当调整
🔢
页码
前置部分（摘要、目录）大写罗马数字 I, II, III；正文阿拉伯数字 1, 2, 3；封面无页码
📑
标题层级
一级标题 三号黑体，二级标题 四号黑体，三级标题 小四号黑体
📚
参考文献
按 GB/T 7714 标准格式自动生成
📎
封面
自动生成符合学校要求的封面页

✧ 所有格式细节均与学校官方要求 100% 一致，无需手动调整。

❓ 常见问题
小白常见疑问解答 ✧

Q：我需要自己安装 Python 吗？

A：如果你使用 AI Agent 安装 方式，AI 会自动处理环境，你不需要安装任何东西。如果你选择 终端安装，需要先安装 Python（3.8 及以上版本）。

Q：工具会修改我的论文内容吗？

A：绝对不会！ 工具只调整格式（字体、行距、页边距、页码等），你的正文、观点、数据、参考文献完全保留，一字不改。

Q：我可以用它排版已经写好的论文吗？

A：当然可以！无论你是刚开始写还是已经写完，都可以使用这个工具进行格式调整。只需上传文件即可。

Q：生成的 Word 文件可以在 WPS 中打开吗？

A：可以！生成的 DOCX 文件是标准格式，Microsoft Word 和 WPS 都可以正常打开和编辑。

Q：我遇到问题了怎么办？

A：可以在 GitHub Issues 中反馈，或者在 AI 对话中直接告诉 AI 你遇到的问题，AI 会帮你解决 ✧
