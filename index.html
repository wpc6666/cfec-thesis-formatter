1 项目特性

从格式规范到输出管理，全流程自动化、可追溯。

📄 双格式输出

一键生成 DOCX（python-docx 原生引擎）与 TeX（XeLaTeX 模板）两份成品，格式完全一致。

🔄 版本化输出 v2.0.0 新增

按论文题目建项目目录，每次格式化自动递增 v1/v2/v3…，历史输出永不覆盖。

🌲 目录树可追溯

项目根目录自动生成 MANIFEST.md 版本清单，交付时附完整目录树。

📐 严格复刻规范

完整复刻学校官方页边距、行距、页码、标题层级、参考文献格式。

🔢 页码规则适配

封面无页码；前置部分大写罗马数字；正文阿拉伯数字从 1 开始。

📚 四级标题体系

一、 → （一） → 1. → (1) 完整层级自动排版，目录只显示到二级。

📊 图表公式编号

图 1-1 / 表 1-1 编号规范；公式右对齐按章节编号；支持三线表。

🔒 安全交付

默认不覆盖原始文件；正文引用 [1] 自动上标；输出前自动校验关键格式项。

2 输出目录树

同一篇论文多次格式化后的标准结构（示例题目：基于深度学习的X研究）。

# 输出根目录（默认当前工作目录） output/ └── 基于深度学习的X研究/ # 项目目录（题目 slug 化，≤40 字符） ├── v1/ # 第 1 次输出 │ ├── 基于深度学习的X研究_v1.docx │ ├── 基于深度学习的X研究_v1.tex │ ├── 基于深度学习的X研究_v1.pdf # 可选：LaTeX 编译产物 │ └── 基于深度学习的X研究_v1_data.json ├── v2/ # 第 2 次输出（自动递增，绝不覆盖 v1） │ └── 基于深度学习的X研究_v2.docx └── MANIFEST.md # 版本清单（时间 / 文件 / 说明）
版本号规则：默认自动取「已有最大版本号 + 1」； 用户可指定版本号，但目标目录非空时拒绝写入（防误覆盖）； DOCX / LaTeX / PDF / 数据 JSON 全部落在同一个 v<N>/ 目录内。

3 安装指南

两种方式任选其一。

  1. Git 克隆本地安装
    # 克隆仓库并复制最新版 Skill 目录到你的 Agent 技能目录 git clone https://github.com/wpc6666/cfec-thesis-formatter.git cd cfec-thesis-formatter cp -R "重财-论文格式规范" ~/.harness/skills/ # 安装 python-docx（DOCX 原生生成引擎依赖） pip install python-docx
  2. 插件市场一键安装

    在 Codex / DeepSeek-Harness 插件市场添加本仓库地址即可安装。 仓库只维护单一最新版 Skill 目录，版本号记录在 SKILL.md frontmatter 与 manifest.json，历史版本由 Git tag 管理。

4 使用指南

直接把这段话发给你的 AI 助手即可。

请使用 cfec-thesis-formatter 处理我的毕业论文，输出符合重庆财经学院 本科格式规范的 DOCX 和 XeLaTeX 两份文件。只调整格式，不要修改论文内容； 输出到版本化目录（项目目录/v<N>/），不要覆盖我之前的版本。
  1. 准备论文 —— 建议纯文本输入，标题用「一、（一）1.(1)」层级标记。
  2. 发送给 AI —— 指定使用本工具处理论文内容。
  3. 获取成品 —— AI 按输出目录树规范生成版本化目录、Word 与 LaTeX 源文件。
  4. 本地核对 —— DOCX 打开后按 Ctrl+A → F9 更新目录域；TeX 用 XeLaTeX 编译两次。

5 常见问题

会修改我的论文内容吗？
绝对不会。本工具只调整格式样式，不改动任何文字、观点、数据和参考文献内容。
重复格式化会不会覆盖我之前的输出？
不会。每次格式化自动进入新的 v<N>/ 版本目录，文件名携带版本号，历史版本与 MANIFEST.md 清单完整保留。
支持哪些学校格式？
当前版本专为重庆财经学院本科毕业论文设计，其他院校可定制开发。
LaTeX 文件怎么生成 PDF？
使用 XeLaTeX 引擎编译（推荐 TeX Live 或 MiKTeX），编译两次以生成目录与交叉引用。
安装后调用没反应？
检查 Skill 是否被正确索引，重启 Agent 服务，确认 SKILL.md 路径配置正确。
