# 课程报告 → 多级项目文件夹

适用于《市场调查综合分析》这类**课程报告**：有学校/课程格式模版、封面和评价表，
但不走毕业论文的 2027 手册流程。

## 两种模式（二选一）

### A. 给模版

```bash
bash <skill目录>/make-report-project.sh \
  --report 报告.docx --template 格式模版.docx \
  [--requirements 课程要求.docx] --out <输出目录>
```

- 从模版切出封面和附件评价表。
- 封面自动填课程名称、项目名称，成员信息留空或 `--info` 补。
- `03-输出/完整报告.docx` = 封面 + 正文 + 附件表。

### B. 不给模版

```bash
bash <skill目录>/make-report-project.sh \
  --report 报告.docx --no-template --out <输出目录>
```

- 不生成封面、附件表，也不套用论文模板。
- 保留原报告自己的标题页，`03-输出/正文.docx` 是唯一成品。
- `01-模板`、`02-封面`、`04-附件材料` 只放 `说明.md`。

### 规则

- `--template` 与 `--no-template` **二选一**；都不给时脚本拒绝执行，并列出三种选择：
  课程模版、2027 论文模版、不要模板。
- 「课程报告要求」不是模版，不放进 `01-模板`；只放 `00-原文件` 与 `04-附件材料`。
- `--out` 省略时输出到当前目录；目标目录非空时拒绝覆盖。
- 首次运行自动建 `.venv` 并装 `python-docx` / `PyYAML` / `lxml`。

## 封面

从格式模版第一切出，保留学校 logo、封面表格和报告成绩栏；
自动填「课程名称」「项目名称」，其余字段留空，避免编造小组成员信息。
需要自动填学院/年级/专业/班级/成员时，传 `--info`：

```yaml
course: "市场调查综合分析"
project: "淘宝网2021年第一季度商品销售运营分析"
college: "经济学院"
grade: "2023级"
major: "经济统计学"
class_name: "23经统X班"
members:
  - name: "张三"
    id: "2023xxxx"
  - name: "李四"
    id: "2023xxxx"
```

## Word 自动导出

- 首次导出会触发 macOS 的“允许控制 Microsoft Word”，点允许即可。
- 也可先运行 `bash <skill目录>/authorize-word.sh` 主动授权。
- 拒绝过就到 系统设置 → 隐私与安全性 → 自动化 → 勾选运行脚本的 App → Microsoft Word。
- 未授权时跳过 PDF，并在 `05-测试/提醒.md` 写明原因。

## 触发条件

只有用户明确调用 `/cfec-thesis-formatter`，或明确说“用重财论文格式规范 / 格式化这份报告”时，
才执行本流程。普通文档整理任务不自动套模板。

## 与毕业论文流程的区别

| 项目 | 课程报告 | 毕业论文 |
|---|---|---|
| 入口 | `make-report-project.sh` | `make-thesis-2027.sh` |
| 模板 | 课程/学校格式模版 | 2027 手册自带模板 |
| 封面 | 模版封面 + 报告成绩栏 | 2027 封面（论文/设计） |
| 附件 | 课程评价表、课程要求 | 11 张学校附件表 |
| 目录 | 报告正文自带或手工 | TOC 域 |

## 已知边界

- 只做格式与拼装，不改写报告内容。
- 课程报告的具体字号、页码格式（如“第×页（共×页）”）以课程要求为准；
  当前正文沿用 2027 格式器的通用参数，必要时在 Word 里微调。
- 封面小组成员、学号、成绩、签字不代填。
