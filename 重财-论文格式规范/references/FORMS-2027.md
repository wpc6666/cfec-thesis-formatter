# 2027 届附件材料

## 装订顺序

封面 → 目录页 → 综合成绩评定表 → 评分表 → 指导教师评阅表 → 交叉评阅表 →
答辩评分表 → 答辩记录 → 任务书 → 开题报告 → 中期检查表 → 指导记录表 →
承诺书 → 查重检测报告 → AIGC 检测报告。

A4 幅面，长尾夹左侧竖装；评分表为 A4 横向，其余纵向。

- 自动填的是基本信息；评语、成绩、签字、日期必须人工完成。

## 附件材料封面

`封面/封面-附件材料.docx`：

- 标题两行：「2027届本科毕业论文（设计）」「附件材料」。
- 字段：题目、学院、年级、专业、**班级**、学号、姓名、指导教师。
- 与正文封面不同，多「班级」，无日期行。

## 专业班级对照表

- `参考/专业班级对照表.docx`：手册原表。
- `参考/专业班级对照表.csv`：`学院,专业名称,班级`，144 条，UTF-8 BOM。
- 用途：填附件材料封面的「班级」，或核对专业全称。

## 重新提取

```bash
cd <skill目录>
.venv/bin/python scripts/2027/extract_templates.py \
  --manual assets/2027/原文件/手册-2027（Word转换版）.docx
```

节号映射在 `scripts/2027/extract_templates.py` 的 `COVERS / FORMS / SAMPLES / MULTI` 表：

- 封面：S2 毕业论文、S3 毕业设计、S10 附件材料
- 附件表：S12–S24（任务书 S18–S19、开题报告 S20–S21 跨节）
- 专业班级对照表：S25

手册改版后先打印节列表核对，再改表。
