# 重庆财经学院毕业论文格式规范速查表（2027 届）

> 全部规则来自《重庆财经学院毕业论文（设计）指导手册（2027届）》，不采用 GB/T 7713.2-2022。
> 执行格式调整时以此文件为权威依据。机器可读参数：`<skill目录>/assets/format.yaml`。

---

## 一、页面设置

| 项目 | 数值 |
|---|---|
| 纸张 | A4，宽 21cm，高 29.7cm |
| 页边距-左 | 2.8cm |
| 页边距-右/上/下 | 2.5cm |
| 装订线 | 0cm，靠左 |
| 页眉 / 页脚 | 1.5cm / 1.75cm |
| 正文行距 | 固定值 26 磅（表格、注释除外） |

## 二、页码

| 位置 | 规则 |
|---|---|
| 封面 | 不编排页码 |
| 前置部分（摘要、Abstract、目录） | 大写罗马数字：I、II、III……连续 |
| 正文（第一章至文末） | 阿拉伯数字：1、2、3……连续 |
| 格式 | Times New Roman 小四，页面底端居中，数字两侧不加修饰线 |

实现：封面后、正文前分别插入分节符（下一页），各节取消“链接到前一条页眉/页脚”，分别设置页码格式和起始编号。

## 三、封面

| 元素 | 格式 |
|---|---|
| 届别标题 | 学校模板自带：`2027届本科毕业论文` / `2027届本科毕业设计` |
| 题目 | 宋体/Times New Roman，四号，**加粗**，居中，无缩进，无段前段后 |
| 学院、年级、专业、学号、姓名、指导教师 | 宋体/Times New Roman，四号，**不加粗**，居中 |
| 指导教师多人 | 用顿号“、”隔开 |
| 附件材料封面 | 额外含「班级」；其余同上 |

- 论文封面：白色平纹纸、A3 幅面、左侧胶装。
- 附件材料封面：A4 幅面、长尾夹左侧竖装。
- 封面不编页码。

## 四、中文摘要

| 元素 | 格式 |
|---|---|
| 位置 | 另起一页，固定行距 26 磅 |
| 标题 | “摘  要”（两字间 2 个半角空格），黑体，小三（15pt），加粗，居中，大纲级别正文文本 |
| 正文 | 宋体/Times New Roman，小四（12pt），两端对齐，首行缩进 2 字符 |
| “关键词：” | 黑体，小四，两端对齐，无缩进；与摘要正文之间空一行 |
| 关键词 | 宋体/Times New Roman，小四；全角分号“；”隔开，最后不加标点 |
| 字数 | 一般 300～1000 字 |

## 五、英文摘要

| 元素 | 格式 |
|---|---|
| 位置 | 另起一页，固定行距 26 磅 |
| 标题 | “Abstract”，Times New Roman，小三（15pt），加粗，居中 |
| 正文 | Times New Roman，小四，两端对齐，首行缩进 2 字符 |
| “Keywords:” | Times New Roman，小四，**加粗**，无缩进；与正文之间空一行 |
| 关键词 | Times New Roman，小四；半角分号“;”隔开，最后不加标点 |

英文标点后要有半角空格，符合英文撰写习惯。

## 六、目录

| 元素 | 格式 |
|---|---|
| 位置 | 另起一页，固定行距 26 磅 |
| 标题 | “目  录”（两字间 2 个半角空格），黑体，小三，加粗，居中 |
| 目录项与标题 | 之间空一行 |
| 显示层级 | 原则上只显示到 2 级 |
| 页码 | 右对齐，制表符前导符为“点”，Times New Roman |
| 一级目录项 | 宋体/Times New Roman，小四，两端对齐，无缩进 |
| 二级目录项 | 宋体/Times New Roman，小四，左缩进 2 字符，右缩进 0，无首行缩进 |
| 颜色 | 黑色；自动目录不要带蓝色超链接 |

目录必须用 Word 域自动生成，不手工输入页码。

## 七、正文标题

| 级别 | 字体/字号 | 编号 | 对齐/缩进 | 大纲级别 |
|---|---|---|---|---|
| 一级 | 黑体，小三 15pt，**不加粗** | 一、二、三、…… | 居中，无缩进；与上一段落之间空一行 | 1 级 |
| 二级 | 黑体，四号 14pt | （一）（二）（三）…… | 两端对齐，首行缩进 2 字符 | 2 级 |
| 三级 | 黑体，小四 12pt | 1. 2. 3. ……（样例写作「1.页面设置」） | 两端对齐，首行缩进 2 字符 | 3 级 |
| 四级 | 宋体，小四 12pt，加粗 | （1）（2）（3）…… | 两端对齐，首行缩进 2 字符 | 正文文本 |

所有标题：无段前段后，行距固定值 26 磅。

## 八、正文文本

- 中文宋体，西文 Times New Roman，小四（12pt）。
- 两端对齐，首行缩进 2 字符，无段前段后。
- 固定行距 26 磅。
- 正文从另页右页开始；毕业论文不少于 8000 字，毕业设计不少于 12000 字（不含摘要、参考文献、附录）。

## 九、图

| 元素 | 格式 |
|---|---|
| 图序 | 按章编号，如 `图1-1`；**「图」与数字之间不留空格** |
| 图序 + 图题 | 中间空 2 个半角空格：`图1-1  长方形` |
| 字体 | 黑体，五号（10.5pt），居中，无缩进，无段前段后 |
| 位置 | 图下方 |
| 标点 | 图题建议不用标点，题后不加标点 |

## 十、表

| 元素 | 格式 |
|---|---|
| 表序 | 按章编号，如 `表1-1`；「表」与数字之间不留空格 |
| 表序 + 表题 | 中间空 2 个半角空格：`表1-1  近两年设计情况统计表` |
| 表序/表题 | 黑体，五号，居中；置于表格上方 |
| 表格内容 | 宋体/Times New Roman，五号，单倍行距 |
| 样式 | 建议国际通用三线表：顶线、表头线、底线，无竖线 |
| 跨页 | 重复表序、表题（加“（续）”）和表头 |

## 十一、注 / 资料来源

- 宋体/Times New Roman，小五（9pt）。
- 两端对齐，首行缩进 2 字符，无段前段后，单倍行距。
- 置于图或表下方。

## 十二、公式与定理

- 公式另起一行，Times New Roman，小四。
- 按章编号，编号置于括号内，如（1.1）（1.2）；编号右对齐，公式内容位于页面中部。
- “定理、性质、引理、推论、定义、证明”等按章编号，黑体，小四，首行缩进 2 字符，后空 2 个半角空格接内容。

## 十三、参考文献

| 元素 | 格式 |
|---|---|
| 位置 | 另起一页，固定行距 26 磅 |
| 标题 | “参考文献”，黑体，小三，1 级大纲，居中，无缩进，无段前段后 |
| 内容 | 宋体/Times New Roman，五号（10.5pt），两端对齐 |
| 缩进 | 悬挂缩进 2 字符，无段前段后，固定行距 26 磅 |
| 编号 | `[1]`、`[2]`……按正文出现顺序；编码后加一个制表位（默认 2 字符） |
| 正文引用 | 上标 `[1]`，Times New Roman，小四 |

常见类型：

1. 图书：`[序号]第一作者,第二作者.书名[M].出版地:出版社,出版年份:引文页码.`
2. 期刊：`[序号]第一作者,第二作者.文献篇名[J].刊物名称,年,卷(期):引文页码.`
3. 学位论文：`[序号]作者.篇名[D].学位授予单位所在地:学位授予单位,学位授予年.`
4. 报纸：`[序号]作者.篇名[N].报纸名,出版日期(版次).`
5. 汇编：`作者.书名[G].出版地:出版社,出版年.`
6. 专利：`[序号]所有者.专利名称:专利申请号[P].公告(公开)日期.`
7. 报告：`[序号]作者.篇名:报告编号[R].[发布日期].网址.`
8. 会议录：`[序号]作者.篇名[C].出版地:出版者,出版年份:起止页码.`
9. 标准：`[序号]标准编号 标准名称[S].`
10. 网页：`[序号]主要责任者.篇名[EB/OL].[发布日期].网址.`

## 十四、附录

| 元素 | 格式 |
|---|---|
| 位置 | 每个附录另起一页；编号、标题各占一行，居中 |
| 附录编号 | `附录A`、`附录B`……大写字母，黑体，小三，1 级大纲，居中 |
| 附录标题 | 黑体，四号，大纲级别正文文本，居中 |
| 附录条文 | 宋体/Times New Roman，小四，两端对齐，首行缩进 2 字符，固定 26 磅 |

## 十五、附件材料（2027 新增）

附件材料单独装一袋，A4 幅面、长尾夹左侧竖装。顺序：

1. 封面（含班级）
2. 目录页
3. 综合成绩评定表
4. 评分表（A4 横向）
5. 指导教师评阅表
6. 交叉评阅表
7. 答辩评分表
8. 答辩记录
9. 任务书
10. 开题报告
11. 中期检查表
12. 指导记录表
13. 承诺书
14. 查重检测报告
15. AIGC 检测报告

- 前 11 项空白模板从手册原样提取：`<skill目录>/assets/2027/模板/附件材料/`。
- 查重、AIGC 报告由学校指定系统导出，不提供仿制模板。
- 表格中的评阅要点、承诺书正文属于学校原文，保留不动。

## 十六、装订顺序（论文正文）

1. 封面（A3，白色平纹纸）
2. 中文摘要（含关键词）
3. 英文摘要（含关键词）
4. 目录
5. 正文
6. 参考文献
7. 附录

## 十七、常见易错点清单

- [ ] “摘要”“目录”两字之间是否空 2 个半角空格（不是全角空格）
- [ ] 中文关键词分隔符是否全角“；”，英文是否半角“;”，最后一个关键词后无标点
- [ ] 图序表序是否为 `图1-1`、`表1-1`，且与题名之间空 2 个半角空格
- [ ] 图题在图下方，表题在表上方
- [ ] 一级标题是否“一、”居中，与上一段落之间空一行
- [ ] 三级标题是否为 `1.` 而不是 `1.1`
- [ ] 正文引用 `[1]` 是否上标，参考文献列表编号是否不上标
- [ ] 参考文献是否另起一页、悬挂缩进 2 字符
- [ ] 目录是否只到二级、条目是否黑色、页码是否右对齐
- [ ] 封面是否无页码；前置部分是否 I、II、III；正文是否从 1 开始
- [ ] 全文行距是否固定 26 磅（表格、注释除外）
- [ ] 页边距是否左 2.8cm、其余 2.5cm
- [ ] 表格是否为三线表、内容是否五号
- [ ] 公式编号是否右对齐、形如（1.1）
- [ ] 附件表顺序是否与装订顺序一致，评分表是否 A4 横向
